# La Cripta del Nigromante

Una aventura lista para jugar para **Dino Tabletop Engine**.

## Contenido incluido
- 🗺️ **Mapa táctico**: Mapa de cuadrícula con niebla de guerra preconfigurada.
- 💀 **Bestiario**: Esqueletos, zombis y el Nigromante menor con tokens e iniciativas.
- 🎲 **Tablas aleatorias**: Encuentros en la cripta y botín de sarcófagos.
- 📜 **Notas y diario**: Pistas y trasfondo para el director de juego.

## Requisitos
- Módulos activados: **Iniciativa y Rastreador de Combate**, **Tablas Aleatorias**, **Bandeja de Dados**.
